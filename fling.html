Fling

Quick capture for iPhone. Type or dictate a note, swipe up, and Fling saves it as plain Markdown to iCloud Drive, a Files folder, or an automation webhook.

Support

Need help with Fling? Email sober@duck.com with your device model, iOS version, and what you were trying to do.

Common Questions

Where do my notes save?

By default, Fling saves notes to iCloud Drive. You can also choose any Files-compatible folder in Settings.

What happens if my destination is unavailable?

Fling tries to save the note locally in the Files app container so your note is not lost.

Do I need an account?

No. Fling does not have accounts, ads, analytics, or tracking.

How do I use webhook delivery?

Open Settings, tap Connect Webhook, and paste a Fling connection link. Fling previews the destination and verifies the link before saving it.

Webhooks

Use a Fling connection link with a secret token and a short destination name.

https://your-domain.example/fling-webhook?token=YOUR_SECRET_TOKEN&slug=personal_notes

Treat the full link as a secret. Fling removes token, slug, and project_slug before saving the endpoint URL, stores the token in the iOS Keychain, and keeps any other query parameters your endpoint needs.

  • Remote servers must use HTTPS.
  • Local development endpoints can use localhost, 127.0.0.1, or .local local-network hosts.
  • Fling verifies with a HEAD request using Authorization: Bearer YOUR_SECRET_TOKEN and X-Fling-Project: personal_notes.
  • A 2xx response passes. A 405 response also passes, because many simple servers only implement POST.

When you swipe a note to a webhook, Fling sends JSON:

{
  "project_slug": "personal_notes",
  "title": "First line of the note",
  "description": "Everything after the first line"
}

For a one-line note, description is omitted. If a webhook send fails, Fling saves the note to the Files app fallback.

app.head("/fling-webhook", (req, res) => {
  if (req.get("authorization") !== `Bearer ${process.env.FLING_TOKEN}`) {
    return res.sendStatus(401);
  }
  res.sendStatus(204);
});

app.post("/fling-webhook", express.json(), (req, res) => {
  if (req.get("authorization") !== `Bearer ${process.env.FLING_TOKEN}`) {
    return res.sendStatus(401);
  }

  console.log(req.body.project_slug, req.body.title, req.body.description);
  res.sendStatus(204);
});

Privacy Policy

Last updated: June 12, 2026

This privacy policy describes how 47 Summers LLC ("we", "us") handles information in connection with Fling.

Summary

Fling is a quick-capture app for saving notes as plain Markdown files. Fling does not require an account, does not include ads, and does not include analytics or tracking SDKs.

What Fling Stores

  • App settings: Fling stores preferences on your device, such as sound, haptics, text size, selected destination, and clear-gesture settings.
  • Folder access: If you choose a custom folder, Fling stores a security-scoped folder bookmark so it can keep saving notes to that folder.
  • Webhook connection: If you connect a webhook, Fling stores the secret token in the iOS Keychain and stores non-secret connection details, such as the destination name and URL, in app settings.
  • Draft text: If you leave an unfinished note, Fling may store that draft locally so it can be restored when you reopen the app.

Notes And Destinations

By default, Fling saves notes to the app's iCloud Drive folder. iCloud syncing is handled by Apple and your Apple ID settings.

If you choose a folder through the Files picker, Fling saves notes to that folder. That folder may be local to your device or provided by another app or cloud storage service.

If you connect a webhook, Fling sends note content to the webhook URL you configured. The destination service may process or store that content according to its own policies. Fling does not operate the webhook destination unless you host it yourself.

If a configured destination is unavailable, Fling tries to save the note locally in the Files app container so the note is not lost.

Microphone And Speech Recognition

Fling asks for microphone and speech recognition permission only if you use voice dictation. Dictation is handled through Apple's system speech-recognition services. Fling does not record, sell, or use your voice for advertising.

Local Network

Fling asks for local network permission only if you connect a local webhook endpoint, such as a development server on your own network.

What Fling Does Not Do

  • require an account
  • collect analytics
  • show ads
  • track you across apps or websites
  • sell personal data
  • upload your notes to a Fling-owned server

Deleting Your Data

You can delete saved notes from the folder where they were saved, including iCloud Drive, a custom folder, or the local Files app container.

You can disconnect a webhook in Settings. You can remove local Fling data by deleting the app from your device. Notes that were already saved to iCloud Drive or another folder may remain in those locations until you delete them there.
